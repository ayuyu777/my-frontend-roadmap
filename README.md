## 环境现状检查（重要）

已实测你机器的情况：

| 项 | 状态 | 要做什么 |
|---|---|---|
| Node.js | ✅ v24.21.0 | 无需处理 |
| Git | ❌ 未安装 | **需要你自己装**，见下方 |
| pnpm | ⚠️ 不在 PATH | 不用管，全程用 `npm` 即可 |
| npm 缓存目录 | ⚠️ 系统目录不可写 | 在项目里安装依赖时加 `--cache ./.npm-cache` |
| 编辑器 | 未知 | 建议 VS Code |

### Git 安装（阶段 A 第一件事）

任选一种，在 PowerShell 里执行：

```powershell
# 方式一：winget（Win10 1809+ 自带）
winget install --id Git.Git -e --source winget

# 方式二：如果 winget 不可用，去 https://git-scm.com/download/win 下载安装包
```

装完**关掉所有终端重开**，验证：

```powershell
git --version
```

然后配置身份（只做一次）：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

> 装完告诉我，我帮你验证并配 SSH、建第一个仓库。
> **为什么必须装 Git**：面试官会看你的 GitHub 提交记录。一片空白的简历，和一年前就开始提交的简历，是两种人。
